# Phase 2 - Core Concepts and Skills

Small practice projects built while learning core programming concepts.

| File | Concepts practised |
|------|--------------------|
| calculator.py | functions, dictionaries, error handling |
| todo.py | lists, dicts, file I/O, JSON, CLI arguments |
| guess_game.py | loops, conditionals, input validation, random |
| tests/test_core.py | unit testing with pytest |

## Run
    python calculator.py
    python todo.py add "Learn Git"
    python todo.py done 0
    python guess_game.py

## Test
    pip install pytest
    pytest
